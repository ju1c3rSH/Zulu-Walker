# 激光对准归零 — 方程与控制律（视觉端↔MCU 端契约）

> 视觉端（MaixCAM2）只负责"测量"——输出归一化误差流；"归零"（控制）在 MCU 端闭环。
> 本文档给出两侧共享的全部方程与常数定义，双方实现都必须与本文一致。

## 1. 视觉端输出（TARGET_DEV 流，data_type=0x03）

每帧 `error_x/error_y ∈ [-5000, +5000]`，定义：

```
error_x = (cx - W/2) / (W/2) * 5000        cx = 靶标色块中心像素 x
error_y = (cy - H/2) / (H/2) * 5000        W,H = 图像分辨率（本项目 640×640）
```

符号约定：目标在画面**右/下**方为正。`flags.bit0`（FOUND 锁存）=0 时误差字段恒为 0，
MCU 严禁使用；flags=0 且连续帧 = 目标丢失。freshness 100ms（MCU 侧判），过期即冻结伺服。

## 2. 归一化误差 → 像素 → 角度

```
ex_px  = error_x / 5000 * (W/2)                       # 反归一化到像素
θ_deg  = atan2(ex_px, f_px)                           # 针孔模型，精确式
f_px   = (W/2) / tan(HFOV/2)                          # 焦距(像素)，HFOV=镜头水平视场角
θ_deg ≈ (error_x / 5000) * (HFOV / 2)                 # 小角度线性近似(|θ|<10° 误差<1%)
```

**HFOV 现场标定**（一次性，10 分钟）：
1. 相机固定，距离 D=1000mm 处水平放两个间隔 S=500mm 的标志点；
2. 数出两点像素间隔 P；
3. `θ_pair = 2*atan(S / (2D))`，`px_per_deg = P / θ_pair`；
4. 反推 `HFOV = 2*atan((W/2) / (P/θ_pair))`。
   等效换算：`θ_deg = ex_px / px_per_deg`（推荐用这条，绕过镜头畸变建模）。

## 3. MCU 控制律（panzer TIM5 tick，Emm addr2 = 76 tick/°）

```
误差角     θ = ex_px / px_per_deg                     （按 §2 标定值）
目标角     yaw_cmd = yaw_hold + sign * θ              sign 按激光器-相机安装方向现场定
死区       |θ| < θ_dz (建议 0.5°)                     → 云台保持不动
比例       Δtick = Kp * θ * 76                        Kp 从 0.5 起调，只在小误差区做
积分(可选) 仅当 1° < |θ| < 2° 时累加，消稳态偏差；超界清零防饱和
```

- Emm 用**绝对角度**模式（`Emm_Pos_Control`），每 tick 重算 `yaw_cmd`，不要发相对步进——避免丢步累积。
- `Car_data.Yaw_Angle`（HWT101）只在底盘航向保持用，云台对准误差一律以视觉误差为源，**两条环不混用**。

## 4. 开火判据（全部满足才允许上激光）

| 条件 | 来源 |
|---|---|
| `DEV_FLAG_FOUND` 锁存（flags.bit0=1） | 视觉，N=5 帧稳定 |
| freshness < 100ms | MCU 侧每帧判 |
| 连续 N=10 帧 `|θ| < θ_dz` | MCU 侧计数（帧=收到的 TARGET_DEV 流帧） |
| `DEV_FLAG_READY`（HIT_CONFIRMED）未置位（还没打过） | 视觉 |

打靶流程：上述满足 → 激光开（建议 650nm 常亮 ~0.5s）→ 等待 `HIT_CONFIRMED`
（人像倒下，视觉锁存）→ 命中确认 → 激光关 → 下一任务。15s 无 HIT_CONFIRMED →
重瞄准（重新伺服）→ 重试 ≤2 次 → 降级/ERROR（MCU 状态机负责，视觉只报事实）。

## 5. 进阶项（现场有需要再做）

- **激光-相机基线偏移补偿**：激光器与镜头光轴平行偏移 b(mm) 时，距离 D 处光点偏离
  画面中心 `Δpx = b / D * f_px`。打靶距离固定（按赛道定），把 Δpx 作为常数偏置加进
  `ex_px` 即可，无需动态测距。
- **ring_id 辅助**：视觉按标定环半径报当前瞄准环（8/9/10），仅用于"往哪环打"的策略，
  命中判据永远以 HIT_CONFIRMED 为准。
- 视觉端自闭环（MaixCAM2 直接驱动舵机云台）只在 MCU PWM 资源不足时启用，协议上加
  LOCKED 事件即可，当前架构不需要。

## 6. 调试顺序（台架）

1. 冻结云台，只看视觉流：手动移靶标，确认 error 符号/幅值与 §1 定义一致（用 `tests/test_eod_color.py` 同款合成帧图样核对）。
2. 标定 px_per_deg（§2），验证 θ 换算：把靶标偏移已知角度，误差换算应闭合到 5% 内。
3. 只闭环 Kp=0.3，观察阶跃收敛；再调死区；最后开积分。
4. 全判据联锁后，先在 3m 内打固定靶，再上赛道距离。
