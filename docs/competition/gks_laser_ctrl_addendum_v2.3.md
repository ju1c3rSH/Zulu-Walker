# USART1 激光控制帧扩展（CMD_LASER_CTRL 0x25）— Brain 联调附录

> 基线：`gks_panzer_links_protocol_v2.1.md`。本附录为该协议的**增量扩展**（记 v2.3），
> 只涉及 USART1 一条链路，**其余两条链路与本帧无任何交互**。
> 视觉端（Zulu-Walker 近端 MaixCAM）已实现本附录定义；本文列出 panzer_Brain 需要实现的部分。

## 1. 背景与目的

近端视觉新增"红点激光校准"调试功能：LASER 调试页需要 Brain 打开板载激光
（PA4 拉低发射），相机拍摄激光点完成 err 零点校准。

v2.1 中从站→主站只有 ACK/NACK/DATA_STREAM 三种帧，没有"从站命令主站"的控制通道，
故新增一个帧类型。**语义为一次性控制命令，不是数据流，不复用 DATA_STREAM。**

## 2. 帧定义

| Type | 名称 | 方向 | Payload（恒 8B） |
|---|---|---|---|
| 0x25 | CMD_LASER_CTRL | **从→主** | `[on_off(1B), reserved(7B, 发送方填 0)]` |

- `on_off`：`0x00` = 关激光，`0x01` = 开激光；其余值视为参数非法（见 §4 处理）。
- 帧外层格式与 v2.1 完全一致：`AA 55 | Length | Type | Payload | CRC16(大端)`，
  `Length = Type + Payload + CRC16 = 11 (0x0B)`，CRC16-CCITT 覆盖 `Type..Payload 末字节`。

## 3. 发送时机与应答约定（视觉端行为契约）

| 时机 | 动作 |
|---|---|
| 进入 LASER 调试页，用户按下 Laser 按钮开 | 发 `on_off=0x01`（仅状态翻转时发，不重复连发） |
| 用户再按一次关 | 发 `on_off=0x00` |
| 退出调试页 / KEY_OK 切页 / 视觉程序退出 | 发 `on_off=0x00`（多条路径兜底自动关） |

- **无应答**：Brain 消费本帧后**不需要**回 ACK/NACK/DATA_STREAM（避免视觉端为收应答引入阻塞）。
- **幂等**：同值重复帧应安全（重复写同一 GPIO 电平无副作用），视觉端只在翻转时发送。
- 本帧与订阅/锁存/心跳机制**无关**：订阅状态、任务锁存、DATA_STREAM 推送均不受影响。

## 4. Brain 侧需要实现的部分（改动点清单）

| # | 位置 | 改动 |
|---|---|---|
| 1 | `Middlewares/serial_protocol` | USART1 解析器**接受帧类型 0x25**：注册处理函数；其余帧类型处理不变 |
| 2 | 同上 | payload 长度校验：`== 8` 才处理；长度不符 → 丢弃 + 调试口计数（不回帧） |
| 3 | 帧处理（建议 interrupt.c 上下文） | `byte[0]==0x01 → PA4 拉低（激光开）`；`byte[0]==0x00 → PA4 拉高（关）`；`byte[0]` 为其他值 → 忽略 + 调试口计数 |
| 4 | USART3 调试回显（沿用 §7.1 约定） | 建议回显一行 `LASER:ON/OFF` 或 `LASER:BAD(b0=xx)`，便于联调对拍；非必须 |
| 5 | （可选，建议）失联自关 | 若实现简单，可加"自上次 ON 帧起 N 秒（建议 10s）未收到任何 0x25 帧则自动关激光"——防视觉端崩溃/断线导致激光常亮。视觉端正常使用中不会触发（开激光后用户一般几秒内完成校准退出）；**不加也不影响联调** |

**明确不需要改的**：

- 0x02 DATA_TARGET 的消费逻辑：err 仍为归一化定点 ×10000，视觉端只是把零点从
  画面中心平移到校准点，数值口径不变，Brain 闭环增益不动。
- 订阅帧、STOP、ACK 的任何处理。
- USART2 / UART4 两条链路。

## 5. 测试向量（串口助手可直接发送）

CRC 按 §1.3 计算，已与 v2.1 文档既有向量对拍验证：

```
USART1 CAM→中控 激光开:  AA 55 0B 25 01 00 00 00 00 00 00 00 8F 91
USART1 CAM→中控 激光关:  AA 55 0B 25 00 00 00 00 00 00 00 00 C8 42
```

解读：`Length=0x0B(11)`、`Type=0x25`、`b0=on_off`、`b1..b7=reserved(0)`、
CRC 大端 `8F 91` / `C8 42`。

## 6. 联调步骤

1. Brain 烧入含 §4 改动的固件，USART1 接线不变。
2. 串口助手（接视觉端 UART）或视觉端调试页发送 §5 ON 帧 → 观察 PA4 电平拉低、激光亮、
   USART3 调试口出现回显（若实现了 #4）。
3. 发 OFF 帧 → 激光灭。
4. 发一帧 payload 只有 2B 的 `AA 55 05 25 01 00 xx xx`（CRC 自行计算）→ 应被丢弃，
   激光状态不变，调试口有计数（若实现了）。
5. 视觉端 LASER 页实测：进页开激光 → 校准 → Exit → 观察视觉端自动补发 OFF 帧、激光灭。
