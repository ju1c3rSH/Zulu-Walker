# LASER_CTRL 指令 — Brain 侧实现说明（协议 v2.1 增补，拟升 v2.2）

> 范围：本文只定义**新增的从站→主站激光控制指令**，其余帧型/订阅语义/推流逻辑零改动。
> 视觉侧（MaixCAM 从站）已按本文实现；Brain 需按下文"实现清单"补齐。

## 1. 背景

近端视觉调试页需要开启车上激光，用相机拍摄红点完成打靶零点校准。
v2.1 中从站→主站仅有 ACK/NACK/DATA_STREAM，无控制方向；故新增一帧型。

- 链路：USART1（视觉链，115200）
- 方向：**从站 → 主站**（本指令 Brain 只收不发，不回 ACK/NACK）

## 2. 帧定义 `0x25 CMD_LASER_CTRL`

帧格式同 v2.1：`AA 55 | LEN | TYPE | PAYLOAD | CRC16(HI,LO)`，
CRC16-CCITT（poly 0x1021, init 0xFFFF, 不反射, 高字节在前），计算 TYPE..payload 末字节。
LEN = Type + Payload + CRC16 = 11 (0x0B)。

| 字段 | 偏移 | 长度 | 说明 |
|---|---|---|---|
| TYPE | 0 | 1 | 0x25 |
| on_off | 0 | 1 | 0x01=开（PA4 **拉高**，激光高有效），0x00=关（PA4 **拉低**） |
| reserved | 1 | 7 | 恒 0x00，接收方忽略 |

### 测试向量（完整帧，Brain 联调可直接灌）

| 动作 | 帧 |
|---|---|
| 开激光 | `AA 55 0B 25 01 00 00 00 00 00 00 00 8F 91` |
| 关激光 | `AA 55 0B 25 00 00 00 00 00 00 00 00 C8 42` |

## 3. Brain 实现清单

1. **解析分支**：`interrupt.c` / serial_protocol 收帧分发处加 `case 0x25`；
   校验 Length==0x0B 且 payload[0] ∈ {0x00, 0x01}。
2. **执行**：payload[0]==0x01 → PA4 **拉高**（激光开）；==0x00 → PA4 **拉低**（激光关）。
3. **非法帧静默忽略**：长度不符/字段非法/未知 type 一律丢弃，**不回任何帧**
   （从站不期待响应，回帧会与推流交织）。
4. **幂等**：重复收到"开"无副作用（视觉侧有心跳重发，见 §4）。
5. **上电默认关**：PA4 初始化为关断电平（激光高有效，故上电写**低**），不依赖视觉侧先发"关"。
6. **零改动确认**：on_cam1 订阅/推流/0x01~0x03 消费逻辑不动；本指令与订阅帧相互独立、可任意交织。

## 4. 视觉侧配套行为（Brain 了解即可）

- **心跳式持有**：进入 LASER 调试页后，视觉侧每 ~2s 重发一次"开"；
- **自动关**：离开调试页 / 页面异常 / 主程序退出 → 视觉侧停止续期并主动发"关"；
- **兜底超时**：视觉侧协调器检测 ~5s 无续期自动补发"关"（页面崩溃路径的保险）；
  Brain 侧**无需**自己做超时关断，但若联调中发现异常常亮，按手动断电兜底。

## 5. 联调步骤

1. Brain 烧录含 0x25 分支的固件，PA4 接激光驱动，万用表/示波器监测 PA4；
2. PC 串口直灌 §2 两个测试向量：PA4 应分别**拉高（亮）/ 拉低（灭）**，无其他副作用；
3. 视觉侧跑 LASER 页按 Laser 键：确认 PA4 翻转 + ~2s 周期重发（幂等无抖动）；
4. 页面 Exit / KEY_OK 切页 / 杀进程三种路径，确认 PA4 均回关断电平；
5. 恢复正常订阅打靶流程，确认 0x01~0x03 推流不受影响。
