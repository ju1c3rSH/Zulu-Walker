# 圆环中心对齐——dr / dθ 推导

> 适用项目：Zulu-Walker（Orange Pi 5B + STM32）  
> 用途：RING_DISCOVERY 阶段视觉伺服，将爪末端对准画面中圆环中心

---

## 1. 物理布局（俯视图）

```
                     trolley 轨道 (径向, 远离 mast 向外)
                              ↑
                              │
      目标圆环 ●                │
               │               │
               │ Δy (径向偏差)   │
               │               │
               │               │
            Δx │           相机 ●────── mast ●──────
     (切向偏差)│            r        (回转中心)
               │
               │
```

**说明：**

| 部件 | 做什么 |
|------|--------|
| **mast（塔身/回转中心）** | 固定在地上，吊臂绕它旋转 |
| **trolley（小车）** | 装在吊臂上，沿吊臂前后滑动（径向） |
| **yaw（回转电机）** | 驱动吊臂绕 mast 旋转 |
| **相机** | 装在 trolley 末端，俯视地面 |

---

## 2. 从图像像素到物理距离

OP（Orange Pi）端已经把图像偏差转换为**归一化的伺服单位**：

```
ex = error_x  取值范围 [-5000, +5000]     (0 = 画面中心)
ey = error_y  取值范围 [-5000, +5000]     (0 = 画面中心)

  +5000 表示目标在画面边缘（偏离中心半个画面宽度）
     0 表示目标在画面正中心
 -5000 表示目标在另一侧画面边缘
```

乘上一个物理缩放因子 `k`（mm / 伺服单位），得到工作平面上的物理偏差（mm）：

```
Δx = k · ex    [mm]     切向物理偏差
Δy = k · ey    [mm]     径向物理偏差
```

`k` 的值取决于相机当前高度和视场角，通过实车标定确定。

---

## 3. 关键洞察：两个独立的单轴问题

trolley 和 yaw 是**两个正交的执行器**，各自只能解决一个方向上的误差：

```
         trolley ──→ 沿吊臂前后走 ──→ 解决 "远/近" 的问题 ──→ Δy
         yaw     ──→ 绕 mast 旋转  ──→ 解决 "左/右" 的问题 ──→ Δx
```

**不需要把 (Δx, Δy) 合成一个向量，两个轴各自独立处理。**

---

## 4. dr 推导——trolley 要移动多少

```
问题：目标在径向偏差 Δy，trolley 该走多远？

         目标 ●
              │
              │ Δy (远了这么多)
              │
         相机 ●
              │
    ────── mast ●──────

答案：trolley 沿吊臂前进 Δy mm 即可消除径向偏差。

    dr = Δy = k · ey
```

这是一个纯平移，**不涉及 r（不需要除以距离）**。

---

## 5. dθ 推导——yaw 要转多少

### 5.1 物理关系

切向偏差 Δx 位于距回转中心距离 r 处。旋转吊臂产生弧线来抵消它：

```
第一步：切向偏差固定，距离为 r

    mast ●
          \
           \  r (与目标无关，是 trolley 当前位置)
            \
         相机 ●──── · 目标
                │
               Δx (切向差了这么多)
```

```
第二步：绕 mast 转一个小角度 Δθ，半径 r 处画出一段弧线

    mast ●
          \
           \  r
            \
             \
          新位置 ● (← 转了 Δθ，trolley 也跟着转了)
             \
         相机 ●─── 弧长 = r · Δθ
                │
                │ Δx
                │
                · 目标

这段弧线恰好压在目标身上 → 误差归零
```

```
第三步：令弧长等于切向偏差

    r · Δθ = k · ex

    →  Δθ = k · ex / r
```

### 5.2 直觉

- 同样 1mm 切向偏差，**r 越小，需转的角度越大**（相机离回转中心近，杠杆臂短）
- r 越大，同样角度转出的弧线越长，所以需转的角度越小
- 除以 r 就是在做**杠杆归一化**

## 6. 为什么不用 sqrt 和 atan2

有两个常见的错误直觉。

### "dr = k · √(ex²+ey²)"

```
     新算法(错误)：        正确做法：

       Δy                    Δy
       ↑  ╲                  ↑
       │   ╲ 对角线           │
       │    ╲            trolley 只看这一个分量
       │     ╲                │
       └──────→ Δx            └──────→ Δx
                              YAW 只看这一个分量

问题：把切向分量也算进径向位移了。
trolley 只能沿径向走，它不该为切向偏差买单。
两个执行器各司其职，不需要勾股定理。
```

### "dθ = k · atan2(ey, ex)"

```
atan2(ey, ex) 是从相机视角看目标的"视线角"（在图像空间里）。

但我们需要的是 mast 这个关节要转的"物理角"。

        mast 关节角 ≈ k·ex/r            ← 我们要的
        atan2(ey, ex) = 目标在画面中的方位角  ← 完全不同的东西

此外：
- k (mm/伺服单位) × 弧度 → 物理量纲错误
- atan2 输出可以到 ±π rad，远超 PID 限幅 ±0.5 rad
```

## 7. 最终公式与代码

```c
// 防除零
if (r < 1.0f) r = 1.0f;

// —— 两个独立轴的计算 ——
dr    = k * (float)servo.error_y;       // 径向: trolley 前后移动
dtheta = k * (float)servo.error_x / r;  // 切向: yaw 旋转

// PID 控制
pdff_ctrl(&pid_r,   0.0f, dr);
pdff_ctrl(&pid_yaw, 0.0f, dtheta);

// 增量驱动（PID 输出 + 当前位置）
Task_SetCranePosition(r + pid_r.out_value, hoist_height);
motor[yaw_motor].ctrl.pos_set = current_yaw + pid_yaw.out_value;
```

## 8. 实车调试清单

| 步骤 | 做什么 | 判据 |
|------|--------|------|
| 1 | 标定 k | 移动 trolley 50mm，观测 ey 变化量，k = 50/Δey |
| 2 | 检查收敛方向 | 开伺服，观察误差是增大还是减小 |
| 3 | 若发散 | 在 `ex` 或 `ey` 前加负号（取决于电机极性） |
| 4 | 调 PID 增益 | kp 从 0.2 起步，逐步加到不振荡的边缘 |
| 5 | 验证 RING_CENTERED | 连续 M 帧 |ex| < N 且 |ey| < N → 居中 |

`r < 1.0f` 的除零保护通常不会触发（mast 到 trolley 有机械最小距离），仅作防御。

## 9. ALIGN_RAW 与 RING_DISCOVERY 的关系

两者算法完全一致。差异仅在：

| | ALIGN_RAW | RING_DISCOVERY |
|---|---|---|
| 视觉任务 | `track_cargo` | `ring_discovery` |
| 收敛信号 | `READY_TO_PICK` | `RING_CENTERED` |
| 收敛后动作 | 切 `PICK_RAW` | 记录电机位置，换下一个颜色 |
| PID 实例 | `pid_align_*` | `pid_goods_*` |
| k 值 | `raw_k_mm_per_px` | `ring_k_mm_per_px` |

公式 `dr = k·ey`，`dθ = k·ex/r` 在两个阶段完全相同。
